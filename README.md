# captKernel plugins

A Claude Code plugin marketplace with captKernel's skill curation, project setup, thinking, writing and everyday tools.

## Install

```
/plugin marketplace add captkernel/plugins
/plugin install <name>@captkernel
```

For example: `/plugin install skills-curator@captkernel`

## Plugins

| Plugin | What it does | Repo |
|---|---|---|
| `skills-curator` | Evaluate, recommend and customize Claude skills before you install them; remembers every decision. | [Skills_Curator](https://github.com/captkernel/Skills_Curator) |
| `claunchpad` | One skill that sets a project up for Claude: CLAUDE.md, persistent memory, agent teams, councils. | [Claunchpad](https://github.com/captkernel/Claunchpad) |
| `thinking-tools` | Council, premortem, red team, pressure test, brutal assessment. | [claude-thinking-tools](https://github.com/captkernel/claude-thinking-tools) |
| `writing-tools` | Humanize, tighten and hook-writing skills. | [claude-writing-tools](https://github.com/captkernel/claude-writing-tools) |
| `everyday-tools` | Cheap flights, fare myths, focus steps, fast learning plans. | [claude-everyday-tools](https://github.com/captkernel/claude-everyday-tools) |
| `instacomp` | Your Instagram shares and saves as a searchable library you can ask questions. Needs the `instacomp` CLI. | [instacomp](https://github.com/captkernel/instacomp) |

## Updates

Updates: run `/plugin marketplace update captkernel`
